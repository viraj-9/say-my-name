# The Heisenberg Files — cinematic fan experience

A responsive, dark-cinematic Breaking Bad fan-site concept. Created for fun purpose.
Visit here - https://say-my-name-six.vercel.app/

## Run locally

From this folder, run:

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Experience details

- **Cinematic Volumetric Smoke Engine**: GPU-accelerated WebGL billowy fractal smoke engine featuring upward convective thermal buoyancy, soft volumetric puff lobes, 3D directional self-shadowing, and atmospheric toxic emerald lighting (zero aquatic ripples or water caustics). Includes an automatic Canvas 2D flow-field fallback for full cross-device compatibility.
- **Physical 3D Voronoi Fragment Assembly**: Authentic Voronoi convex polygon fragmentation using Sutherland-Hodgman clipping. Irregular crystalline shards with variable density (fine shards on Walter White's facial features, larger structural shards on periphery) that tumble in 3D perspective space (pitch, yaw, roll, Z-depth) and lock seamlessly into place as you scroll.
- **Cinematic Sound Design & Audio Engine**: User-controlled audio playback with animated equalizer bars, master mute/unmute button in the header, volume popover slider, and keyboard shortcut (`M`). Features legal, real-time procedural Web Audio API sound design: sub-bass assembly lock resonance, periodic table resonant chemical chirps, timeline era switch clicks, and return-to-top atmospheric air whoosh.
- **Scroll-Driven Storytelling**: 5 cohesive movie scenes connecting The Awakening, The Fragments, The Identity, The Atmosphere, and The Finale without deleting or displacing any original content.
- Responsive navigation, scroll progress bar, atomic chemistry tile decoding, and an interactive 4-era character descent timeline.
- Fully honors `prefers-reduced-motion` and pauses off-screen rendering for maximum battery and CPU/GPU efficiency.
